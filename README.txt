GHOST NETRUNNER CHECKLIST — MOBILE PWA

EASIEST: Open CP2077_Ghost_Netrunner_Mobile_Checklist.html on your phone in Chrome or another browser. Tap to complete tasks. Progress is stored in that browser on that device if local-file storage is allowed. Use Gear / Save > Export backup regularly.

INSTALL AS A REAL HOME-SCREEN APP (GitHub Pages):
1. Make a GitHub repository and add index.html, manifest.webmanifest, sw.js, icon-192.png and icon-512.png from this ZIP at its root.
2. Open repository Settings > Pages and enable deployment from main branch, root folder.
3. Visit the GitHub Pages HTTPS URL on Android Chrome.
4. Open browser menu and select Install app or Add to Home screen.
5. Check off steps. Progress saves locally on that device. Export your JSON backup before clearing site data or switching devices.

No account, ads, analytics, network APIs, or external dependencies.
